## Aditya Paradkar

Quant systems for Indian markets, and the tooling around them.
[aditya-paradkar.in](https://aditya-paradkar.in)

**Trading** — `statrex`, a personal algorithmic trading system (Python + Rust, TimescaleDB), and `quant_toolkit`, a library for NSE/BSE derivative contracts, holiday-aware expiries and OHLCV storage. Both private. The options research is public: [covered-call-simulator](https://github.com/cheesecakeMafia/covered-call-simulator) prices a million Monte Carlo paths across two covered-call strategies, while [India-VIX1W](https://github.com/cheesecakeMafia/India-VIX1W) and [OptionChain](https://github.com/cheesecakeMafia/OptionChain) are earlier work on weekly-expiry VIX and volatility skew.

**Tooling** — [mstat](https://github.com/cheesecakeMafia/mstat) and [xfer](https://github.com/cheesecakeMafia/xfer), Bash CLIs for a three-machine Tailscale fleet; GNOME Shell extensions for the things I check daily; and the site above, a FastAPI + HTMX app that grew into a small tool platform.

Occasionally I build a game to learn something — [rust-game](https://github.com/cheesecakeMafia/rust-game), [system-design-game](https://github.com/cheesecakeMafia/system-design-game).
